# 隐私与安全说明

Context Distiller 遵循**最小权限**和**最小留存**两条原则。

## 一句话

插件在你的浏览器里、当前对话页面内完成提取、选择和编译，**不上传、不自动发送**；默认**不持久化**对话内容——除非你主动开启「记住本次整理」，届时也**只存到本地浏览器、绝不外传**（见下）。读取完整长对话时，会用你**现有的登录态**向 **ChatGPT 自己的后端**发一个**同源 GET**请求取当前对话，内容只在本地处理、不外传（见下）。

## 权限说明

| 声明 | 为什么需要 |
| --- | --- |
| `sidePanel` | 在 AI 页面旁边展示工作台（Side Panel） |
| `scripting` | 从 content script 向页面主世界注入读取脚本 |
| `storage` | 保存你自己的长期配置（标记「长期」的自定义模块名 / 自定义要求文本）；以及**你主动开启**「记住本次整理」时的本次快照（对话 + 已选材料），只存本地、关闭即清除。默认不保存任何对话内容 |
| host: `*://chatgpt.com/*`、`*://chat.openai.com/*` | 只在明确支持的 ChatGPT 页面运行 content script、读取当前对话、回填输入框 |

插件**没有**申请：`tabs`（跨标签页）、`cookies`、`<all_urls>`、后台网络等权限。

## 做什么，不做什么

- ✅ 只在 chatgpt.com / chat.openai.com 运行。
- ✅ 只处理**当前对话页面**中的数据。
- ✅ 对话内容在浏览器内存中完成提取、选择和编译。
- ✅ 为读取**完整**的长对话，会用你**已登录的 ChatGPT 会话**向 **ChatGPT 自己的后端接口**（同源 `chatgpt.com`）发一个 **GET** 请求取当前对话——与网页本身加载对话是同一来源、同一凭据；取回的内容只在你浏览器内存里处理，**不发往任何第三方**。
- ✅ 只把**你自己的配置**（标记「长期」的自定义模块名、自定义要求文本、以及**便签**里的批注）写入 `chrome.storage.local`。
- ✅「**便签**」只是本地的个人批注本：随手记的内容只存进本地 `chrome.storage.local`、跨会话保留，**永不编译进输出、永不外传**——它跟你选材料编译出的纯文本毫无关系（这一点与会被编译进【标记】段的「消息标记」正好相反）。
- ✅「在对话里定位」只把你**已经打开**的对话页**滚动**到某条消息并高亮一下（纯本地 DOM 操作）——不发任何请求、不触碰你的账号，无封号风险。
- ❌ 不读取你的账号密码。为调用 ChatGPT **自己**的接口读取对话，会**临时使用**你当前的 ChatGPT 会话令牌（同源就地获取、用完即弃、**不存储、不外传**）——和网页自己请求对话用的是同一个凭据。
- ❌ 不把任何内容上传到插件服务器（插件根本没有服务器）。
- ❌ **默认不把对话内容 / 选中材料写入本地存储**——只有你主动开启「记住本次整理」时才会存一份**本地**快照（绝不外传、关闭即清除）；否则这些只在内存里。
- ❌ 不触发发送按钮，也不模拟键盘提交。

## 数据留存

- **默认**下，你本次选择的消息、模块顺序、备注和预设选择**只保存在侧边栏运行期间的内存里**，
  **关闭 / 刷新 / 重启后会丢失**。
- 例外一：你**主动标记「长期」**的自定义模块名和自定义要求，作为配置存进 `chrome.storage.local`，
  下次打开还在；标记「本次」的只活在内存里。
- 例外二（**默认关闭**）：底部的「记住本次整理」开关。打开后，本次对话 + 已选材料 + 预设选择会
  快照到本地 `chrome.storage.local`，下次打开原样恢复；**只存本地、绝不外传**，关闭开关（或下次
  打开时检测到未开启）会立即清除该快照。是否开启完全由你决定。
- 这是主动的产品取舍：默认不落盘（避免演变成笔记库、省掉隐私管理成本），需要长期留存时再由你亲手开启。

## 读取范围 vs. 使用范围

插件为了让你看到完整对话，可能会读取当前对话的全部（已加载）消息；但**只有你主动选择的
材料**才会进入最终编译出的纯文本消息。

点「填入当前对话」后，文本只进入当前页面的输入框；**只有你自己点发送**，内容才会按 ChatGPT
自己的机制提交给模型。插件不参与、也不记录这一步。

## 首次使用提示

界面在空状态会说明：关闭或刷新侧边栏会丢失当前选择；插件不保存历史；插件不会自动发送。
「清空本次整理」按钮随时可用，且在有材料时会二次确认。
