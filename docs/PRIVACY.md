# 隐私与安全说明

Context Distiller 遵循**最小权限**和**最小留存**两条原则。

## 一句话

插件在你的浏览器里、当前对话页面内完成提取、选择和编译，**不上传、不持久化、不自动发送**。

## 权限说明

| 声明 | 为什么需要 |
| --- | --- |
| `sidePanel` | 在 AI 页面旁边展示工作台（Side Panel） |
| `scripting` | 从 content script 向页面主世界注入读取脚本 |
| host: `*://chatgpt.com/*`、`*://chat.openai.com/*` | 只在明确支持的 ChatGPT 页面运行 content script、读取当前对话、回填输入框 |

插件**没有**申请：`tabs`（跨标签页）、`storage`（本地存储）、`cookies`、
`<all_urls>`、后台网络等权限。

## 做什么，不做什么

- ✅ 只在 chatgpt.com / chat.openai.com 运行。
- ✅ 只处理**当前对话页面**中的数据。
- ✅ 对话内容在浏览器内存中完成提取、选择和编译。
- ❌ 不读取账号、密码、登录凭据或浏览器 Cookie。
- ❌ 不把任何内容上传到插件服务器（插件根本没有服务器）。
- ❌ 不写入 IndexedDB / `chrome.storage` 等长期本地数据库。
- ❌ 不触发发送按钮，也不模拟键盘提交。

## 数据留存

- 你本次选择的消息、模块顺序、备注和设置，**只保存在侧边栏当前运行期间的内存里**。
- **关闭侧边栏、刷新扩展页面或重启浏览器后，这些内容会丢失**，MVP 不保证恢复。
- 这是主动的产品取舍，用来避免插件演变成笔记库，并省掉存储、迁移、备份和隐私管理成本。

## 读取范围 vs. 使用范围

插件为了让你看到完整对话，可能会读取当前对话的全部（已加载）消息；但**只有你主动选择的
材料**才会进入最终编译出的纯文本消息。

点「填入当前对话」后，文本只进入当前页面的输入框；**只有你自己点发送**，内容才会按 ChatGPT
自己的机制提交给模型。插件不参与、也不记录这一步。

## 首次使用提示

界面在空状态会说明：关闭或刷新侧边栏会丢失当前选择；插件不保存历史；插件不会自动发送。
「清空本次整理」按钮随时可用，且在有材料时会二次确认。
