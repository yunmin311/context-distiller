# 使用指南

## 安装

开发中直接用 `pnpm dev`（自动打开带扩展的浏览器）。或手动加载已构建版本：

1. `pnpm build`
2. `chrome://extensions` →「开发者模式」→「加载已解压的扩展程序」→ 选 `.output/chrome-mv3`
3. 打开一个 [chatgpt.com](https://chatgpt.com) 对话，点工具栏的 Context Distiller 图标打开侧边栏。

## 基本流程

1. **读取对话**：**打开侧边栏即自动读取**，无需手动点。读取走 ChatGPT 自己的后端接口，
   **超长对话也一次读全**（不受它「只挂载一屏」的虚拟化限制）。顶栏的刷新图标可随时重读；
   万一失败会自动重试几次，仍不行时按提示刷新页面。

2. **选目标模块**：默认五个模块——框架 / 正文内容 / 补充 / 复盘 / 关键语句。
   消息列表顶部常驻的「加入到」选择器决定新材料落到哪个模块，也可在那里新建模块
   （可选「本次」或「长期」）。

3. **选材料**，三种粒度：
   - **整条**：消息上点「＋加入」。
   - **问答组合**：用户消息上点「＋问答」，把这条提问和它的下一条回答一起加入。
   - **局部文本**：**直接在侧边栏的消息里划词**，弹出的小条里可顺手写条注释再「＋加入」。

   另外，点消息上的 **📌** 可以标记这条并写批注——标记会编译进独立的**【标记】**段；
   顶部的 `📌 N` 可切换「只看已标记」。点消息的 **#编号** 能让左侧 ChatGPT 滚到并高亮那条。

4. **整理**：在工作区里对每个片段上移/下移、删除、加备注、**点正文就地编辑**，
   或用「移到…」换模块；片段上的准星按钮同样能在左侧对话里定位它。

5. **点预设按钮**（底部「预设 Prompt」区）：
   - **输出用途**（单选）：快速回顾 / 高密度笔记 / 学习版本 / 研究记录 / 对话续接
   - **知识密度**（单选）：低 / 中 / 高
   - **文风**（单选）：专业直接 / 自然易读 / 学术严谨 / 保留原表达
   - **输出结构**（单选）：Markdown / 连续段落 / 结构化提纲 / 必要时表格
   - **附加要求**（多选）：保留关键原句 / 保留术语 / 禁止新增观点 / 保留未解决问题 / 合并重复 / 保留示例

   单选组里再点一次当前选项可取消。悬停按钮看它的作用说明。
   附加要求可以「＋自定义」：给它起个名字，或点**「从库导入」**从内置离线提示词库挑一条
   （总结提炼 / 分析审视 / 改写润色 / 结构化 / 迁移交接）填进来再改，可选「本次 / 长期」保留。

6. **预览**：底部点「预览」，看到完整纯文本和字符数。

7. **交给 AI**：
   - 「复制」→ 粘到任意对话，或
   - 「填入」→ 文本进入 ChatGPT 输入框。

   **插件不会自动发送。** 填入后请自己检查并点发送。

## 小提示

- 默认下关闭 / 刷新侧栏会**丢失本次整理**（这是有意设计）。想留住就打开底部
  **「记住本次」**（默认关闭）：本次对话与整理快照到本地，下次打开原样恢复，关闭即清除。
- 顶栏的**「便签」**是纯私人批注本：跨会话一直保留，**永远不会进编译输出**
  （和会编译的「消息标记 📌」正好相反）。
- 「填入」失败时（ChatGPT 输入框有时是复杂编辑器），改用「复制」——它始终可用。
- 「清空」会清掉所有已选材料、标记和备注（有内容时会二次确认）。
- 面板明暗会自动跟随 ChatGPT 的主题。
- 顶栏的 **中 / EN** 切换界面语言，选择会长期保留。注意它**同时切换编译出来的提示词**：
  基础指令、预设、提示词库、默认模块名都会换成英文版本，段落括号也从 `【框架】` 变成 `[Frame]`。
  **你自己写的内容不会被翻译**——自定义要求、备注、批注、你命名的模块、便签都原样保留。
  首次打开时按浏览器语言自动判断，手动切过一次之后就以你的选择为准。

## 测试清单（手动 / E2E）

依赖真实 ChatGPT 页面、无法纯单测覆盖的部分，请在浏览器里覆盖：

- [ ] 读取：区分用户 / 助手；顺序正确；标题正确；**超长对话一次读全**（不用手动翻）。
- [ ] 选材：整条、问答组合、划词片段（含划词注释）都能进对应模块。
- [ ] 标记：📌 标记 + 批注；`📌 N` 切「只看已标记」；预览里出现独立的【标记】段。
- [ ] 定位：点 #编号 / 片段准星，左侧 ChatGPT 滚到并高亮；被虚拟化的远处消息也能找到。
- [ ] 便签：顶栏便签写入后关面板重开仍在；**预览里绝不出现便签内容**。
- [ ] 提示词库：自定义要求「从库导入」能填入、可改名、可保存为长期。
- [ ] 编组：上移/下移、删除、备注、就地改正文、跨模块移动。
- [ ] 预设：五组按钮都改变预览；单选互斥、多选叠加；再点取消。
- [ ] 编译：预览顺序 = 基础 → 用途 → 密度 → 文风 → 结构 → 附加 → 材料。
- [ ] 回填：填入 ChatGPT 输入框成功，且**没有**自动发送。
- [ ] 复制：剪贴板拿到完整文本。
- [ ] 清空 / 刷新：内容消失，后台没有偷偷持久化。
- [ ] 内容类型：中文、英文、中英混合、代码块、列表、表格、超长回答。
- [ ] 环境：深色模式、页面缩放、窄侧栏、虚拟列表长对话。
- [ ] 主题：在 ChatGPT 里切换深 / 浅色，面板跟着变。
- [ ] 语言：点 中 / EN，界面全部换语言、**预览里的提示词也换**（`[Frame]` / `[Marks]` / `(note: …)`）；
      默认模块名跟着改而**已分到该模块的片段不动**；自定义要求与各类备注**保持原文不被翻译**；
      关掉面板重开语言仍是上次选的那个。
