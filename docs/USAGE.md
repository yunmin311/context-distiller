# 使用指南

## 安装

开发中直接用 `pnpm dev`（自动打开带扩展的浏览器）。或手动加载已构建版本：

1. `pnpm build`
2. `chrome://extensions` →「开发者模式」→「加载已解压的扩展程序」→ 选 `.output/chrome-mv3`
3. 打开一个 [chatgpt.com](https://chatgpt.com) 对话，点工具栏的 Context Distiller 图标打开侧边栏。

## 基本流程

1. **读取对话**：在 ChatGPT 对话页点侧栏顶部「读取对话」。侧栏会列出消息，用蓝/青色边区分
   用户与助手。若是超长对话，会提示「可能不完整」——向上滚动加载更多后再点「刷新」。

2. **选目标模块**：工作区默认有五个模块——框架 / 正文内容 / 补充 / 复盘 / 关键语句。
   模块标题左边的圆点是「目标模块」，新加入的材料都会落到它里面。也可以「添加模块」。

3. **选材料**，三种粒度：
   - **整条**：消息卡片上点「加入」。
   - **问答组合**：用户消息上点「加问答」，会把这条提问和它的下一条回答一起加入。
   - **局部文本**：先在 ChatGPT 页面里用鼠标选中一段文字，再回侧栏点顶部「捕获选区」。

4. **整理**：在工作区里对每个片段上移/下移、删除、加备注，或用「移到…」换模块。

5. **点预设按钮**（底部「预设 Prompt」区）：
   - **输出用途**（单选）：快速回顾 / 高密度笔记 / 学习版本 / 研究记录 / 对话续接
   - **知识密度**（单选）：低 / 中 / 高
   - **文风**（单选）：专业直接 / 自然易读 / 学术严谨 / 保留原表达
   - **输出结构**（单选）：Markdown / 连续段落 / 结构化提纲 / 必要时表格
   - **附加要求**（多选）：保留关键原句 / 保留术语 / 禁止新增观点 / 保留未解决问题 / 合并重复 / 保留示例

   单选组里再点一次当前选项可取消。悬停按钮看它的作用说明。

6. **生成并预览**：底部点「生成并预览」，看到完整纯文本和字符数。可以直接改预览文本
   （只影响这次输出，不改按钮和片段）。

7. **交给 AI**：
   - 「复制完整消息」→ 粘到任意对话，或
   - 「填入当前对话」→ 文本进入 ChatGPT 输入框。

   **插件不会自动发送。** 填入后请自己检查并点发送。

## 小提示

- 关闭 / 刷新侧栏会**丢失本次整理**（这是有意设计）。重要内容先「复制」。
- 「填入」失败时（ChatGPT 输入框有时是复杂编辑器），改用「复制」——它始终可用。
- 「清空」会清掉所有已选材料和备注（有材料时会二次确认）。

## 测试清单（手动 / E2E）

依赖真实 ChatGPT 页面、无法纯单测覆盖的部分，请在浏览器里覆盖：

- [ ] 读取：区分用户 / 助手；顺序正确；标题正确。
- [ ] 选材：整条、问答组合、局部选区都能进对应模块。
- [ ] 编组：上移/下移、删除、备注、跨模块移动。
- [ ] 预设：五组按钮都改变预览；单选互斥、多选叠加；再点取消。
- [ ] 编译：预览顺序 = 基础 → 用途 → 密度 → 文风 → 结构 → 附加 → 材料。
- [ ] 回填：填入 ChatGPT 输入框成功，且**没有**自动发送。
- [ ] 复制：剪贴板拿到完整文本。
- [ ] 清空 / 刷新：内容消失，后台没有偷偷持久化。
- [ ] 内容类型：中文、英文、中英混合、代码块、列表、表格、超长回答。
- [ ] 环境：深色模式、页面缩放、窄侧栏、虚拟列表长对话。
